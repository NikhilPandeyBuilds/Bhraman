# 🧭 Bhraman

> **Discover Beyond the Obvious. From Places → To Plans.**

Bhraman is an intelligent travel-planning application designed to move beyond generic "nearby places" and search results.

Instead of simply finding places, Bhraman tries to understand **what the traveler actually wants**, determine what is realistically reachable, build an itinerary around those constraints, and adapt the plan when circumstances change.

**Intent → Understand → Reach → Plan → Adapt → Discover**

---

## 🚀 What is Bhraman?

Travel planning is rarely just about finding the highest-rated place nearby.

A useful recommendation depends on constraints such as:

- ⏱️ Available time
- 💰 Budget
- 👥 Group size
- 📍 Current location
- 🚗 Transportation mode
- ❤️ User interests
- 🌦️ Real-world conditions
- 🔄 Changing circumstances

Bhraman converts these requirements into a structured planning problem and generates experiences that fit the traveler rather than forcing the traveler to fit a generic recommendation.

---

## ✨ Core Capabilities

### 🎙️ 1. Natural Intent Input

Users can express their requirements through **voice or text**.

For example:

> "I have 3 hours, ₹3,000, three friends, and we're around Bandra. Find something interesting we can actually do."

Instead of treating this as a simple keyword search, Bhraman extracts meaningful constraints from the request.
